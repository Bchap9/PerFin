# Security controls register

Maps every row of [SECURITY.md](../SECURITY.md) (A1-I4) and
[AI_ACCESS.md](../AI_ACCESS.md) (M1-M8) to the code that implements it and
the tests that prove it. Anyone adding or changing a control updates its row
in the same change (see [DEVELOPMENT.md](../DEVELOPMENT.md)). Status is one
of `implemented`, `partial (what is missing)` or `planned (Phase N)`. At 1.0
no row may be `planned`.

Paths are relative to the repository root.
